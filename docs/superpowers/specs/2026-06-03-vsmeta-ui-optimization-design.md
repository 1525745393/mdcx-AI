# VSMeta 界面配置优化设计

**日期**: 2026-06-03
**状态**: 已确认

## 概述

对 VSMeta 界面配置进行优化，提升用户体验，包括：模板预览、预设管理、语法验证等功能。

## 优化项

### 1. 模板预览功能

**功能描述**: 用户输入自定义模板后，实时显示渲染效果预览

**实现方案**:
- **预览数据**: 使用模拟示例数据（虚构但合理的番号、标题、演员等信息）
- **显示位置**: 内嵌在设置页面，自定义模板输入框下方
- **样式**: 简洁文本框，显示"预览："前缀 + 渲染后的文本，浅色背景
- **更新时机**: 用户输入时自动更新预览

**示例数据**:
```python
{
    "number": "ABC-123",
    "title": "测试标题",
    "originaltitle": "テストタイトル",
    "publisher": "测试发行商",
    "studio": "测试片商",
    "series": "测试系列",
    "actors": "演员A、演员B",
    "director": "测试导演",
    "outline": "这是中文简介",
    "originalplot": "これは日本語の梗概です",
    "year": "2024",
    "release": "2024-01-15",
    "runtime": "120",
    "score": "8.5",
    "genre": "剧情",
}
```

### 2. 预设模板管理

**功能描述**: 用户可保存自定义预设，存储在配置文件中

**实现方案**:
- **存储位置**: 存储在配置文件中，与现有配置一起保存
- **支持操作**: 创建自定义预设、删除自定义预设
- **UI**: 在下拉框旁添加"保存当前配置为预设"按钮和删除按钮

**数据结构**:
```python
@dataclass
class VsmetaCustomPreset:
    name: str
    show_title_type: int
    show_title2_type: int
    summary_type: int
    custom_title: str
    custom_title2: str
    custom_summary: str
```

### 3. 模板语法验证

**功能描述**: 输入时实时检查模板语法正确性

**实现方案**:
- **验证时机**: 输入时实时验证
- **验证内容**: 检查 `{if:}` 和 `{/if}` 是否配对
- **错误提示**: 配对错误时显示红色边框

**验证逻辑**:
```python
def validate_template_syntax(template: str) -> tuple[bool, str]:
    """验证模板语法，返回(是否有效, 错误信息)"""
    depth = 0
    for i, char in enumerate(template):
        if template.startswith("{if:", i):
            depth += 1
        elif template.startswith("{/if}", i):
            depth -= 1
            if depth < 0:
                return False, "{/if} 没有对应的 {if:}"
    if depth > 0:
        return False, "{if:} 没有对应的 {/if}"
    return True, ""
```

### 4. 智能默认值

**功能描述**: 在帮助文档中强调默认值语法

**实现方案**:
- 在模板帮助说明中添加更多 `{field|默认值}` 使用示例
- 帮助信息中明确说明：字段为空时使用默认值语法

**更新后的帮助文档**:
```
【默认值语法】
• 语法：{field|默认值} - 字段为空时使用默认值
• 示例：{title|无标题} - 标题为空时显示"无标题"
• 示例：{actors|未知演员} - 演员为空时显示"未知演员"
```

### 5. 批量操作

**功能描述**: 提供重置和导出功能

**实现方案**:
- **重置功能**: 添加"重置为默认"按钮，一键重置所有VSMeta设置
- **导出功能**: 添加"导出配置"按钮，导出当前VSMeta配置为独立JSON文件

**导出文件格式**:
```json
{
    "version": 1,
    "exported_at": "2026-06-03T12:00:00",
    "vsmeta_config": {
        "vsmeta_include_poster": true,
        "vsmeta_include_backdrop": true,
        ...
    }
}
```

### 6. UI交互优化

**功能描述**: 优化预览区域的样式和交互

**实现方案**:
- **预览区域**: 浅色背景（`#f5f5f5`），文本框样式，显示渲染后的实际效果
- **更新机制**: 输入即更新，无需手动触发
- **预览标签**: 显示"标题预览："、"副标题预览："、"简介预览："等前缀

### 7. 帮助信息增强

**功能描述**: 改进占位符列表的展示方式

**实现方案**:
- **占位符列表**: 折叠可展开，默认折叠，点击"查看更多占位符"展开完整列表
- **悬停提示**: 不实现，保持现有简单样式

**布局调整**:
```
[帮助标签 - 可折叠]
  ▼ 点击展开
  【基础占位符】...
  【增强语法】...
```
